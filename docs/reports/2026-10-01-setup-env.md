# รายงาน: ตั้งค่าสภาพแวดล้อมโปรเจค (feat/setup-env) — 1 ต.ค. 2569

## ทำอะไรไป
1. **Pin เวอร์ชันไลบรารี** ลง `requirements.txt` และ `requirements-dev.txt`
   - ใช้ `uv pip compile --universal` แทน `pip-compile` เพราะได้ไฟล์เดียวที่ใช้ได้ทั้ง Windows, Mac และ Linux
     (เช่น `pywin32` จะติดตั้งเฉพาะบน Windows, `uvloop` เฉพาะบน Mac/Linux)
   - วิธี pin ใหม่เขียนไว้ที่หัวไฟล์ `requirements.in`
2. **เปลี่ยนเป็น Python 3.12 ทุกที่** (Dockerfile 2 ไฟล์, CI) ให้ตรงกับเครื่องสมาชิก
   ถ้าใช้ 3.11 ใน Docker แต่ 3.12 ในเครื่อง numpy และ shap จะได้คนละเวอร์ชัน
3. **เพิ่ม `pyproject.toml`** ให้ `pip install -e .` แล้ว `import demand` ได้ทุกที่ และตั้งค่า ruff กับ pytest
4. **แก้ `src/demand/config.py`** อ่านไฟล์เป็น utf-8 และเพิ่ม `get_mlflow_tracking_uri()` ที่ให้ env `MLFLOW_TRACKING_URI` ชนะค่าใน config
5. **ข้อมูลตัวอย่างสำหรับ CI** `scripts/make_sample_data.py` สร้างข้อมูลจำลอง 10 ร้าน ครบทุกช่วงเวลาใน config (seed 42 ได้ไฟล์เดิมทุกครั้ง)
   - จำลองจุดยากของข้อมูลจริง: ร้านที่ 3 ไม่มีข้อมูลครึ่งหลังปี 2014, มี 5 วันที่เปิดแต่ยอดเป็น 0, ร้านที่ 5 ไม่มีข้อมูลคู่แข่ง
   - ใช้ข้อมูลจำลองแทนข้อมูลจริง เพราะกติกา Kaggle ไม่ให้เผยแพร่ข้อมูลซ้ำ
6. **ข้อมูลจริง** แตก `train.csv` และ `store.csv` จาก `rossmann-store-sales.zip` ลง `data/raw/` (ไม่ commit)
7. **test ใหม่** `tests/test_config.py` (4 ข้อ) และ `tests/test_fixtures.py` (3 ข้อ)
8. อื่นๆ: `make lint` และ CI ตรวจโฟลเดอร์ `scripts/` ด้วย, เพิ่ม `make sample-data`, `.gitignore` เพิ่ม `mlflow_data/` และ `*.egg-info/`

## ปัญหาที่ยังค้างและขั้นต่อไป
- **ยังไม่ได้ทดสอบ Docker** เพราะ Docker Desktop ในเครื่องยังไม่เปิด
- ปิดกฎ E501 (บรรทัดยาว) ของ ruff เพราะ docstring เดิมหลายไฟล์ยาวเกิน 100 ตัวอักษร
- job `data-validation` และ `model-gate` ใน CI จะผ่านโดยยังไม่ได้ตรวจจริง จนกว่า A และ B จะเขียน `schema.py` และ `gating.py`
- ติดตั้งครั้งแรกบน Windows ใช้เวลานาน (มากกว่า 10 นาที) เพราะไลบรารีเยอะ
- Mac รุ่น Intel จะได้ numba เวอร์ชันเก่าที่อาจไม่รองรับ Python 3.12 (ถ้ามีสมาชิกใช้ Mac Intel ให้แจ้ง)
- ขั้นต่อไป: ทุกคนแตก branch จาก `main` หลัง merge แล้วเริ่มส่วนของตัวเองได้ เริ่มจาก A (ingest, split, schema)
